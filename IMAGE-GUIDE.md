## Suggested LinkedIn-style wording

### MiniPlay
Full-stack music streaming web application built using PHP, MySQL and XAMPP, with authentication, music discovery, albums, artists, genres, liked songs, search and playlists. The project demonstrates database design, backend integration and a complete user-facing music workflow.

### ResQ
Smart ambulance and SafeRoute routing system built with Flutter and Python-based routing services. The project combines emergency dispatch, hospital routing, safer travel, traffic-aware navigation, SOS workflows and an operations dashboard for real-time intervention.
