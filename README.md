# Able Thomas — Premium Portfolio

Static GitHub Pages portfolio using plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure and content
- `style.css` — premium dark-blue/light theme, responsive layout and animations
- `script.js` — theme toggle, scroll reveal, navigation, progress bar and working Back to Top button
- `IMAGE-GUIDE.md` — exact asset filenames plus captions/descriptions for the screenshots

## Add the screenshots later
Create the following folders and place your images inside them. Keep the filenames exactly as listed in `IMAGE-GUIDE.md` so the site picks them up automatically.

```text
assets/
├── miniplay/
└── resq/
```

The portfolio is intentionally shipped without the assets folder so you can add/edit the images yourself before committing.

## Deploy
Upload/replace `index.html`, `style.css`, `script.js`, `README.md` and `IMAGE-GUIDE.md` in the root of `able-t22/able-t22.github.io` and commit to `main`.

GitHub Pages URL:
`https://able-t22.github.io/`
